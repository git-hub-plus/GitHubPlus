# 한국어 번역 용어집

GitHub+의 한국어 번역은 다음 표기를 기준으로 한다.

| 원어 | 한국어 |
| --- | --- |
| commit | 커밋 |
| push | 푸시 |
| pull | 풀 |
| fetch | 가져오기(fetch) |
| branch | 브랜치 |
| merge | 병합 |
| rebase | 리베이스 |
| stash | 임시 저장(stash) |
| repository | 저장소 |
| clone | 복제(clone) |
| remote | 원격 |
| pull request | 풀 리퀘스트 |
| cherry-pick | 체리픽 |
| tag | 태그 |
| diff | 변경 내용 |
| conflict | 충돌 |
| discard | 버리기 |
| revert | 되돌리기 |
| amend | 수정(amend) |
| squash | 합치기(squash) |
| history | 히스토리 |
| changes | 변경 사항 |
| preferences | 환경설정 |

Windows 메뉴의 액세스 키는 `파일(&F)`처럼 표기한다. 브랜드는 `GitHub+`로 표기한다.
